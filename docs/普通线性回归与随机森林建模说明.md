# 普通线性回归与随机森林容量预测

当前只保留两种主要模型：普通最小二乘多元线性回归与随机森林回归。容量保持仅提供比较基线，不列为第三种主要模型。

## 数据与特征

原始4块电池共636条容量记录，读取results/step01/battery_clean.csv。统计限幅数据只作敏感性对照，不替换模型目标。独立特征入口为src/comparison_common.py。

预测第t次容量，输入为目标循环次数、上次容量、此前5次容量均值及线性斜率。先shift(1)后rolling(5)，不读取第t次及未来真实容量。前5次仅作历史，得到616个建模样本。24℃恒定，不作为输入。

## 训练与预测

每块电池独立拟合，时间顺序划分。B0005、B0006、B0007训练目标6至100，验证101至134，测试135至168；B0018训练6至79，验证80至105，测试106至132。

普通回归：四个输入标准化后用最小二乘求系数，无正则化和参数搜索，保存原始单位及标准化系数。

随机森林：300棵树，bootstrap=True，max_features=1.0，random_state=25121619，n_jobs=1。max_depth为2、4、None，min_samples_leaf为3、8，共6候选。每块电池只按验证RMSE选择，严格同分采用预设顺序首个，共24条搜索记录。选定最大树深前三块不限、B0018为4，叶最少样本均为3。

两种模型在测试前用训练加验证重新拟合，估计器在整个测试段固定。每次预测时可以获得此前刚测量的真实容量，曲线由多次单步预测组成。两种模型及基线拥有相同129个测试目标。

## 当前结果

| 方法 | 四电池平均测试MAE Ah | 四电池平均测试RMSE Ah |
| --- | ---: | ---: |
| 普通线性回归 | 0.011871 | 0.017370 |
| 随机森林回归 | 0.051188 | 0.058766 |
| 容量保持比较基线 | 0.009264 | 0.014425 |

以上先逐电池计算再等权平均，合并129点的指标另存pooled_test.csv，不混用。B0006回归RMSE为0.011730 Ah，略低于基线0.012239 Ah。B0018森林RMSE为0.028542 Ah，低于回归0.033624 Ah，但仍高于基线0.027251 Ah。

前三块电池有32/34、33/34、32/34个测试容量低于各自最终拟合容量的最小值，森林在这三块电池的全部测试点上高估。叶节点均值及其平均不能低于拟合容量最小值，直接预测绝对容量的这一森林方案存在明显外推限制。该结论针对当前方法与划分，不推广为所有森林方案必然无效。

## 复现与验证

运行顺序及依赖见README.md。模型与预测在results/step06、results/step07，统一核对和比较在results/step08，图表在figures/step08。worked_example.json记录B0006第135次的四个输入、第一棵树路径以及300棵树的输出范围和均值。

当前共19项测试通过（数据清洗7项、跳变对照3项、回归5项、森林4项），包含历史特征与当前未来容量隔离、时间边界、回归参数公式重建、森林候选选择及保存模型复现。加上第九步的18项，全仓共37项。24组指标均由逐点预测独立重算，各方法的目标编号、实测值与原始CSV一致。清理公共依赖后，两种模型的逐点预测保持不变。

普通回归、随机森林算法原始提交为a1a2940、8e4d38e。所有新增算法或修改独立提交并推送，删除通过新提交执行，历史留痕保留。

仅4块电池、24℃及一个已查看的测试时间段，不视为新电池外部盲测。历史窗口相关，不虚构置信区间。当前只验证容量预测，不直接声称剩余寿命或飞行时长准确。
