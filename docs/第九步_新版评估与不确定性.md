# 新版容量预测评估与不确定性分析

本步骤对应报告第6章及第7章使用维护建议。基于0b358f3版本的普通最小二乘回归、随机森林以及容量保持比较基线重新计算，不恢复旧岭回归方案，也不替换原始观测或组员已有结果。

## 运行与产出

先按README完成01、06、07、08步骤，然后运行：

```sh
python src/09_evaluation_and_uncertainty.py
python -m unittest discover -s tests -v
```

读取results/step01/battery_clean.csv和results/step08/predictions.csv。输出results/step09、figures/step09；已有输入只读。代码优先自动选择微软雅黑等中文字体。

## 6.1 误差大小与容量高估风险

每种方法使用同样129个测试目标。四块电池分别计算指标，不能把不同模型对同一目标的预测当成独立样本。误差定义为预测减实测；正值为容量高估。保存MAE、RMSE、平均偏差、高估比例、最大高估和绝对误差90%分位数。

四电池等权平均RMSE分别为：普通回归0.017370 Ah，随机森林0.058766 Ah，容量保持基线0.014425 Ah。这不是合并129点后计算的RMSE，两种汇总口径不可混用。

随机森林在B0005、B0006、B0007的所有测试点上高估容量；结合第八步拟合范围诊断，说明本方案的后期外推存在限制。普通回归整体偏低估，容量保持基线总体误差最低但平均偏差为正。不能据低估就断言更安全，也不能把容量误差直接换算成飞行分钟数。绝对误差90%分位数是描述统计，不是未来90%预测区间。

## 6.2 研究阈值与预警适用范围

阈值固定为各电池首循环容量的80%，不是制造商额定容量定义的SOH、更换或安全标准。首次跨越定义为首次实测小于或等于阈值，不要求持续低于。

| 电池 | 首次实测跨越循环 | 原模型测试起点 |
|---|---:|---:|
| B0005 | 101 | 135 |
| B0006 | 61 | 135 |
| B0007 | 124 | 135 |
| B0018 | 75 | 106 |

因此，原单步预测测试段不能验证首次事件的提前预警。低容量状态的分类指标与首次事件检出分别记录；单步事件仅在正确预测首次跨越目标时计为检出、提前1次。若先误报而后真正跨越时漏报，不能给出成功提前量。

### 独立的探索性滚动诊断

为补充跨越前的观察，沿用预先固定方案：第30次起，每个起点只使用当时历史，比较容量保持与最近20次线性趋势，预测未来5次内是否首次跨越阈值。每次起点重拟合，未来实测仅作为评估标签。它们是辅助诊断，不是对现有普通多元回归或随机森林重新调参，也不是两种主模型的多步效果。

| 电池 | 最近20次线性趋势有效提前量 | 误报起点数 |
|---|---:|---:|
| B0005 | 漏报 | 0 |
| B0006 | 1次 | 0 |
| B0007 | 5次 | 5 |
| B0018 | 5次 | 3 |

容量保持在尚未跨越时不预测首次跨越，因此四块均漏报。该现象说明单步误差低不等于能预测退化事件，不否定其原单步基线用途。

有效预警要求真实事件处于报警起点之后的1—5次内，更早误报不算成功。已经观察到首次跨越就停止，即使容量回升也不当作新首次事件。末尾未来不足5次且未跨越时，标签未知、不计为负样本；不足5次但已发生事件时，正标签已知可计分。

每种方法有241个起点，实际事件只有4个。窗口相互重叠，误报起点也可能连续，不能解释为独立误报警情或据此宣称普遍成功率。这是同四块已被查看过的电池上的探索性回测，不是外部盲测；本轮未按结果调整窗口和阈值。

## 6.3 寿命外推敏感性

仅用每块电池前30%、50%、70%历史拟合容量对循环次数的直线，求到达同一研究阈值的交点。历史起点取记录比例，属于回顾性敏感性实验；与已获得上次真实容量后的单步预测不同。斜率非负、交点不在未来或历史已跨阈值时不输出有效剩余寿命。未观测到跨越时标记右删失，不能把记录末尾当寿命。

| 电池 | 前30%历史估计到达循环 | 前50% | 前70% | 首次实测跨越 |
|---|---:|---:|---:|---:|
| B0005 | 228.61 | 115.09 | 已跨越 | 101 |
| B0006 | 68.57 | 已跨越 | 已跨越 | 61 |
| B0007 | 216.71 | 121.01 | 118.09 | 124 |
| B0018 | 63.00 | 83.14 | 已跨越 | 75 |

例如B0005只用前50次时估计偏晚127.61次，用前84次时偏晚14.09次；B0018增加历史后则由偏早变偏晚。历史增加不保证每次更准确。不同窗口的结果范围不是置信区间，也不用于回顾挑选最佳方案。

## 6.4 局限与第7章建议

本轮没有建立统计预测区间。四块电池、恒温24℃、相同已查看数据及相关历史窗口限制了结论范围。首循环参考值、测量波动、局部回升和未来退化速度变化都会影响阈值时刻。数据没有任务能耗、电压电流时序或内阻，不能推出真实续航时长、内阻变化或事故概率。

建议分电池持续跟踪；接近研究阈值时结合新实测和设备规范复核；不要仅凭早期线性交点决定更换日期；对当前随机森林后期容量高估保持审慎，并同时查看偏差和最大高估。具体维护阈值与安全余量需要设备规范和新数据支持，本实验不给通用数值。
