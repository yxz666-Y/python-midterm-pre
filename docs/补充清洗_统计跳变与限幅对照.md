# 补充清洗：统计跳变与限幅对照

原先检查确定的是缺失值0、重复记录0、非正容量0、循环缺口0，不能将此表述成“没有任何异常值”。统计离群与数据错误是两回事。

## 检测规则

先按电池分组，计算相邻变化量delta=Q(t)−Q(t−1)。直接对容量本身筛离群容易把正常衰减后的低容量误判为错误，因此改为检查容量变化。

每块电池仅用前60%记录的变化量估计Q1和Q3（分别为25%、75%分位数），IQR=Q3−Q1。用统一的预设规则：

- delta低于Q1−1.5IQR或高于Q3+1.5IQR：标记待核查。
- delta低于Q1−3IQR或高于Q3+3IQR：标记极端跳变，进入限幅对照。

阈值不使用验证、测试段估计。训练段内部的标记是事后诊断，会利用同一训练段后面的观测，因此本脚本不能声称是逐循环在线早期预警器。若以后在交叉验证中比较处理方案，必须在每个训练折内重新拟合阈值。

这些是按本规则识别的跳变观测，不能说58个错误值或30个测量错误。它们可能涉及容量恢复、测试过程变化或测量波动，缺少原始实验日志，无法确认原因。

## 实际处理

保留全部636行，在单独的敏感性数据中对30个极端跳变做限幅：

Q处理(t)=Q原始(t−1)+clip(delta(t), Q1−3IQR, Q3+3IQR)。

没有删除记录、改变循环编号、补造缺失值，也没有覆盖原始容量。未命中的606条记录保持不变。上一循环采用原始值，避免一次修正导致后续所有容量累积偏移；这也意味着它不是物理退化模型，不保证处理后完全消除局部跳变。

| 电池/循环 | 原容量Ah | 相邻变化Ah | 限幅对照容量Ah |
|---|---:|---:|---:|
| B0006 / 90 | 1.593600 | +0.151900 | 1.467350 |
| B0018 / 46 | 1.726700 | +0.131200 | 1.615675 |
| B0007 / 90 | 1.688800 | +0.098100 | 1.621050 |
| B0005 / 90 | 1.605800 | +0.088300 | 1.546100 |

处理前后四块电池首末容量均未变，全段线性斜率仍为负，整体下降方向保持。最大单点调整为0.12625 Ah，可能压低真实恢复峰值，因此本版本仅作为敏感性对照，不将其称为更准确的真值。
