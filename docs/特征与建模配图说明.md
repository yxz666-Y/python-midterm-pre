# 特征与建模配图说明

以下图片使用 Matplotlib 绘制，读取已有清洗数据及保存的模型结果，不重新训练或调整模型。

| 图片 | 建议放置位置 | 可直接采用的图注 |
| --- | --- | --- |
| `figures/modeling/01_feature_extraction.png` | 5.1 预测目标与特征提取 | 图5-1 历史容量窗口与四个输入特征。以B0006第135次预测为例，均值和斜率仅使用第130至134次容量，第135次实测容量只作为评价标签。 |
| `figures/modeling/02_time_split.png` | 数据划分与模型训练 | 图5-2 各电池按时间顺序划分训练、验证与测试段。前5次仅提供历史，共形成616条建模样本，其中测试目标129个。 |
| `figures/modeling/03_linear_prediction.png` | 5.2 普通线性回归 | 图5-3 普通线性回归的单次预测计算。使用B0006最终模型的原始尺度系数，预测第135次容量为1.331979 Ah。 |
| `figures/modeling/04_random_forest_prediction.png` | 随机森林 | 图5-4 随机森林的单次预测过程。左侧展示第1棵树的实际判断路径，右侧展示300棵树对同一样本的预测，平均值为1.332541 Ah。 |
| `figures/modeling/05_test_rmse_comparison.png` | 两种方法比较或模型评价 | 图5-5 两种模型与容量保持基线的测试RMSE比较。右表为四块电池RMSE的等权平均；容量保持基线约为0.0144 Ah，线性回归约为0.0174 Ah，随机森林约为0.0588 Ah。 |

两种主模型使用相同的四个输入；容量保持基线只使用上一次容量。测试期间模型固定，每次预测前更新已经测得的历史容量，属于滚动单步预测。

第1棵树的叶节点输出按抽样次数计算加权均值，不能把叶内的独立记录数误认为参与平均的抽样总次数。

图片中的RMSE属于当前数据与时间划分下的结果，不代表模型在所有电池或所有预测场景中的表现。
