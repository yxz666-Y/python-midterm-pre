# 普通线性回归与随机森林容量预测

本轮回应用户对两类方法区分的要求。此前两轮主要改变预测距离，岭回归仍是线性模型。本轮以普通最小二乘线性回归作为简单回归，以随机森林回归作为树集成机器学习方法，统一预测下一次循环容量。普通线性回归在广义上也属于监督学习，课程分类中的“简单回归”和“机器学习”不是互斥的数学分类。

## 在查看新实验结果前固定的口径

- 原值保留版数据，不使用统计限幅对照替换测试目标。每个电池单独拟合，不在电池之间随机混合记录。
- 两种模型均使用目标循环次数、上次容量、此前5次容量均值和此前5次斜率。普通回归为四变量多元线性回归，并非只用一个变量的一元直线。
- 目标为第t次容量，容量特征最多到t−1。先排除缺少完整窗口的前5次，得到616个样本。
- 每电池按原始循环数60%和80%设边界。前三块训练目标6–100、验证101–134、测试135–168；B0018训练6–79、验证80–105、测试106–132。
- 普通线性回归无正则化，不搜索超参数。仅在拟合段计算标准化参数，再以最小二乘求系数。
- 随机森林使用300棵树、bootstrap=True、max_features=1.0、random_state=25121619、n_jobs=1。候选为max_depth=[2,4,None]与min_samples_leaf=[3,8]的6种组合，各电池只根据验证RMSE选取，严格同分时采用上述顺序的第一个。
- 测试前以训练加验证段重拟合。估计器在整段测试固定，每次单步预测可以使用之前新测得的真实历史容量，不用测试目标训练模型。
- 保存容量保持基线。评价MAE、RMSE、平均偏差和最大绝对误差，四电池等权平均与合并点误差分别标明。
- 第六步普通回归单独提交并推送，第七步随机森林单独提交并推送，之后再提交图表和报告。不因为测试误差不好而追加算法或搜索参数。

## 解释范围

这是同四块电池和已查看过的时间段上的新增方法比较，不是新的盲测结果。样本小、历史窗口相关、容量有局部回升。随机森林用叶内训练容量的均值预测，可能难以外推到训练范围之外的低容量，复杂方法不保证胜出。当前任务评估容量预测，不能直接声称已验证剩余寿命或飞行时长。
